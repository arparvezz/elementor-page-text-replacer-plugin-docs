Features

Small plugin, focused job

Built for people who create many location pages from a single Elementor design.

🎯

Targets one page

Only the selected page's _elementor_data is changed. Other pages and templates stay untouched.

👁

Dry run mode

See exactly how many replacements will be made before anything is written to the database.

🧩

Works across widgets

Headings, text editors, buttons, tabs, accordions and image alt text stored in Elementor.

⚡

Fast workflow

Clone, set the new slug, enter the page ID and run. Repeat for 30 locations in minutes.

🔒

Admin only

Lives under Tools → Elementor Text Replacer in the WordPress dashboard.

🪶

Lightweight

A single PHP file. No bloat, no settings pages, no front-end code.

✅ What it changes

  • Headings and text editor widgets
  • Button text (and links, if they contain the text)
  • Image alt text stored in Elementor
  • Tabs, accordions and other widget fields

🚫 What it won't normally touch

  • Global header and footer templates
  • Navigation menus
  • Other pages and blog posts
  • WordPress and theme settings
Installation

Installed in under two minutes

Upload the plugin folder using your file manager or SFTP.

1

Add the plugin folder

Open /wp-content/plugins/ and create this structure:

/wp-content/plugins/
└── elementor-page-text-replacer/
    └── elementor-page-text-replacer.php

Paste the plugin code into the PHP file.

2

Activate it

Go to Plugins → Installed Plugins and activate Elementor Page Text Replacer. Then open Tools → Elementor Text Replacer.

Usage

Find the ID, dry run, then replace

Always preview first. Then run the real replacement once the count looks right.

1

Find the page ID

  1. Go to Pages → All Pages.
  2. Click Edit (not "Edit with Elementor").
  3. Look at the URL in your browser.
wp-admin/post.php?post=7&action=elementor

Here the page ID is 7.

2

Run a dry run

Enter the page ID, the text to find and the replacement. Keep Dry Run checked and click Run Replacement. Nothing is changed. You just see the count.

Run the real replacement

After replacing

Go to Elementor → Tools → Regenerate CSS & Data, clear your cache plugin and hosting cache, then check the page in an incognito window.

Troubleshooting

Common questions

Quick fixes for the most common issues.

The plugin says Elementor data is missing
  • Make sure the page was built with Elementor.
  • Confirm you entered the correct page ID.
  • Check the ID by clicking Edit, not Edit with Elementor.
Replacement worked but the frontend shows old text
  • Elementor → Tools → Regenerate CSS & Data.
  • Clear your cache plugin and hosting cache.
  • Open the page in an incognito window.
The dry run shows too many replacements
The old text may also appear in hidden sections, tabs, buttons, links or image alt text on that page.
Header or footer still shows the old city
Headers and footers are usually separate Elementor templates with their own IDs. Edit that template separately, or run the plugin with the template's own post ID.
Will it change other pages on my site?
No. It only updates _elementor_data for the single post ID you enter.
